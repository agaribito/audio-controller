# Audio Controller

## 概要
各アプリケーションの音量を個別に調整できるWindows向けオーディオコントローラーです。

## 特徴
- 起動中のアプリケーションごとの音量スライダー表示
- Windowsの音量ミキサーとリアルタイムに連動
- .NETランタイム不要でexeファイル単体で動作可能

## 動作環境
- Windows 10 / 11 (64bit)

## 使い方
1. `audio controller.exe` をダブルクリックして起動します。
2. スライダーを動かして、各アプリの音量を調整します。
3. 画面の空いている部分を左クリックしたままドラッグすることで、ウィンドウを移動できます。
4. アプリを終了する場合は、ウィンドウを閉じるか、通知領域のアイコンから終了してください。

## インストール方法
ZIPファイルを解凍し、任意のフォルダに配置して実行するだけで使用できます。
